# Deployment Notes

## Frontend
- Deploy the Vite app from the frontend directory to Vercel.
- Set environment variable VITE_API_URL to the backend URL.

## Backend
- Deploy the backend app on Render.
- Set environment variables for database URL, secret key, and algorithm.

## Database
- Use Neon PostgreSQL or any managed Postgres instance.
- Apply the SQL schema in database/schema.sql.
